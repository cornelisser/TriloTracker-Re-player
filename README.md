Sources can be compiled with Sjasm (http://www.xl2s.tk/) or Glass (https://grauw.nl/projects/glass/).

For Glass users:
- Glass-compatible PSG+SCC replayer code is available in `TT_Re-player_PSG-SCC/code_glass/`
- Glass-compatible PSG SFX replayer code is available in `SFX_Re-player_PSG/code_glass/`
- A ready-to-run MSX ROM example is in `TT_Re-player_PSG-SCC/example_ROM_Glass/` (run `make` to assemble with `glass`)
